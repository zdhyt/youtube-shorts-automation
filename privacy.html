Privacy Policy

Last updated: September 8, 2026

This Privacy Policy explains how the YouTube Shorts Automation application handles information when it is used by its owner.

Information the application accesses

The application may access files stored in the owner's Google Drive, including video files and generated metadata files, in order to perform the requested automation.

The application may also access YouTube-related information required to research content and perform authorized publishing operations.

How information is used

Google Drive files are used only to process videos, research relevant information, generate titles, descriptions and hashtags, and support the owner's YouTube Shorts workflow.

Data sharing

The application does not sell personal information. Information is not shared with third parties except when necessary to use the Google services required by the application or when explicitly authorized by the owner.

Data storage and security

OAuth credentials and API credentials are stored using protected GitHub repository secrets. The application is intended for personal use by its owner.

Data retention

Files processed by the application remain in the owner's Google Drive according to the owner's folder and workflow settings. The application does not intentionally retain personal information beyond what is required for the automation.

Contact

For questions about this application or this Privacy Policy, contact the application owner through the contact information associated with the Google account used to operate the application.
